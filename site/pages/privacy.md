# 개인정보 처리방침

| 항목 | 내용 |
|---|---|
| 버전 | 1.0 |
| 시행일 | 2026년 10월 ○일 |
| 운영 주체 | 다온클라우드 |
| 연락처 | contact@daon.cloud (개인정보 보호책임자: 홍준호 대표) |

머리말:

> DaON News는 회원가입이나 로그인 없이 이용할 수 있습니다. 사이트 운영과 피드백 처리에 꼭 필요한 정보만 처리하며, 개인정보를 판매하지 않습니다.

이 방침은 DaON News(https://news.daon.cloud)에 적용되며, 이 방침에 없는 사항은 회사 홈페이지의 [개인정보처리방침](https://daon.cloud/privacy)을 따릅니다.

## 1. 브라우저에만 저장되는 정보

즐겨찾기, 읽음 기록, 화면 테마(라이트/다크), 최근 검색어(최대 10개), 업데이트 소식 확인 여부, 작성 중인 피드백은 이용자의 브라우저(로컬 저장소)에만 저장되며 서버로 전송되지 않습니다. 목록 위치·스크롤 위치 등은 현재 탭의 세션 저장소에만 있고 탭을 닫으면 지워집니다. 브라우저 데이터를 지우면 함께 삭제되고, 다른 기기와 동기화되지 않습니다. 사이트는 이용자 추적용 쿠키나 외부 방문 통계 도구를 사용하지 않습니다.

## 2. 피드백

- 처리 항목: 피드백 내용, 이메일(선택), 작성한 페이지 주소, 첨부한 스크린샷(선택), 남용 방지 식별값(IP 주소와 브라우저 종류로 만든, 원래 값으로 되돌릴 수 없는 해시값)
- 목적: 피드백 확인과 회신, 서비스 개선, 스팸·남용 차단
- 보유 기간: 접수일로부터 1년이 지나면 자동으로 삭제합니다. 남용 차단 목록에 오른 식별값은 차단이 풀릴 때까지 보관합니다.

## 3. 접속 기록

사이트를 운영하는 서버와 웹 프록시(인그레스)는 보안과 장애 대응을 위해 접속 기록(IP 주소, 접속 시각, 요청한 주소, 브라우저 정보)을 남길 수 있습니다. 이 기록은 [보관 기간 확인 후 기재]일 동안 보관한 뒤 삭제합니다.

## 4. 처리 위탁과 국외 이전

사이트와 데이터는 Oracle Cloud Infrastructure(대한민국 춘천 리전)에서 운영합니다. 피드백 내용은 외부 AI 모델로 보내지 않습니다. 요약 생성 시 외부 AI 모델로 보내는 것은 공개 소식원의 기사뿐이고, 이용자 개인정보는 포함되지 않습니다.

## 5. 제3자 콘텐츠

사이트는 외부 원문의 요약과 링크를 보여 줍니다. 원문 링크를 누르면 해당 외부 사이트로 이동하며, 그곳에는 해당 사이트의 개인정보 처리방침이 적용됩니다.

## 6. 정보주체의 권리

이용자는 자신이 제출한 피드백 정보의 열람, 정정, 삭제, 처리 정지를 언제든지 요구할 수 있습니다. contact@daon.cloud로 요청하시면 지체 없이 조치합니다.

## 7. 방침의 변경

이 방침의 내용을 추가, 삭제 또는 수정할 때는 시행 7일 전부터 사이트에 알립니다.
