【제목 자기완결 규칙 — 독자가 열어 보지 않아도 "누구에 관한 무슨 일"인지 알게 한다】

1. 제목은 반드시 핵심 주체를 드러내야 한다: 모델명 / 제품명 / 회사명 / 프로젝트명.
2. 원래 제목이 이미 주체를 분명히 드러낸 경우: 영문 제목은 한국어로 번역하고 한국어 제목은 원뜻을 유지하되, 고치기 위한 고침은 하지 않는다.
3. 원래 제목이 버전 번호 / 코드명 / 정보 없는 teaser(예: "v2.1.159", "Small is a feature", "Day 1", "중대 발표")뿐일 때는 【출처】와 본문을 참고해 주체를 제목에 보충한다. 예: 원제 "v2.1.159" + 출처 "Claude Code: GitHub Releases" → "Claude Code v2.1.159 공개".
4. 주체 보충은 【출처】나 본문에 실제로 등장한 이름만 쓸 수 있다. 본문과 출처 어디에도 구체적 모델명이 없으면 상위어(예: "오픈소스 멀티모달 모델")로 대신하고, "업계 상식"으로 구체적 모델/버전/숫자를 절대 지어내지 않는다.
5. 원래 제목이 표현한 【글의 유형과 핵심 동작】은 넘지 말아야 할 경계다: How / Why / Guide / Analysis / Review / Benchmark 같은 설명·분석·튜토리얼·평가 제목은 한국어 제목에서도 그 유형을 유지해야 한다. 본문이 이미 존재하는 모델·제품이나 새 데이터를 다룬다고 해서 "공개 / 출시 / 론칭 / 오픈소스화"로 바꿔 쓰면 안 된다. 원제가 공개·출시·론칭·오픈소스를 명시적으로 선언했을 때만 한국어 제목이 그에 해당하는 동작을 쓸 수 있다. 유형 유지가 주체 삭제를 뜻하지는 않는다. 1~4번에 따라 본문이나 출처가 명시한 회사·제품·프로젝트명은 그대로 보충한다.
   예: 원제 "How GPT-5.6 fuses frontier intelligence with frontier efficiency" → "GPT-5.6 는 어떻게 최전선 지능과 효율을 함께 잡았나", "OpenAI, GPT-5.6 공개"로 쓰면 안 된다.
   예: 원제 "How to build interactive experiences with canvases" + 출처와 본문이 GitHub Copilot 임을 명시 → "GitHub Copilot 으로 canvases 를 활용해 인터랙티브 경험 만들기", 주체가 빠진 "canvases 로 인터랙티브 경험 만들기"로만 쓰면 안 된다.
